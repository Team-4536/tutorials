# Things to include when creating a tutorial:

- **A goal:** State what this tutorial teaches and what the student should be capable of at the end
- **prerequisites:** State what a student must already have completed / are capable of doing before continuing this tutorial.
- Explanations, examples, walkthrough
- Practice problems (put these in a dedicated file inside of the respective folder)
- Put included images in a seperate folder and link to them to add them to your file

You use VSCode, [Github](https://github.com), or [this website](https://markdownlivepreview.com) for writing your markdown (.md) tutorial
