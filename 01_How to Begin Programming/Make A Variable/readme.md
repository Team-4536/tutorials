## **MAKE A VARIABLE**

_Goal: Learn what a variable is as well as how to create one in python_

**Variable:** A variable is a letter, symbol, or word that represents something else

**Common Variable Types:**

```
Integers (int): represents any whole number

Strings (str): represents any string of words

Booleans (bool): represents a true/false statemen
```

We use variables frequently in python and write them using the following syntax:

[letter, symbol, or word] = value

For example:

numberOfRoations: int = 1

Or

foodType: str = “Fruit”

Or

onOff: bool = True

You can name a variable almost anything that you want. However, when you name variables in python, your variable names may not include minus operator signs, special characters, or spaces.
