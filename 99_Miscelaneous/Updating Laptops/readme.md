# Updating Laptops

## Getting Laptops Up-To-Date

### Prerequisites

Make sure that each laptop is on the MinuteBots wifi before going through the following steps. Also, ensure that the ‘automatically connect’ option is toggled ‘on’ for our team’s wifi.

### Keep Inventory

Throughout the process of preparing the laptops for the next year/season, keep track of which laptops are in your possession through the [Laptop Statuses & Assignments](https://docs.google.com/spreadsheets/d/1Dsyo9l5xjSfFSF_nF2TfSaEkGLjvbIwroWLAd7KlUts) spreadsheet in our team’s google drive.

### Updating Windows

<u>**Primary**</u>

1. Open settings, go to the ‘Windows Update’ tab at the bottom of the list,
2. If the option presents itself, press ‘Check for updates’ and wait for it to finish
3. Next, press the ‘Download and install all’ button, and if that doesn’t work, manually press ‘download’ for each of the updates that appear.
4. Wait for each to download and install their updates. Some of them will require the laptop to restart; Do so if prompted.
5. If your final update has been installed, double check that there are no more by pressing the ‘Check for updates’ button again. If there are more, repeat the process, otherwise you are done with the main updates.

<u>**Additional**</u>

1.  After completing all of the ‘main’ updates, go into the ‘Advanced options’ tab inside of ‘Windows Update’.
2.  Toggle each of the following options to ‘on’, if they are not already set to on.
    <ol type="a">
    <li>‘Receive updates for other Microsoft products’</li>
    <li>‘Get me up to date’</li>
    <li>‘Notify me when a restart is required to finish updating’</li>
    </ol>
