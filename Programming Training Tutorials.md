# Laptop Settings

## System

**Display**

- Set the ‘Scale’ to 100\.  
- If this is not an option, then click on ‘Scale’ to open up ‘Custom scaling’ and set it to 100\.

**Power & battery**

- You should turn on a multitude of settings for optimizing the laptop’s batteries. You can either do this by setting each setting individually, or by turning many on at once and then editing two of them. Option 1 is the quick way; option 2 is the manual way.  
1) Go to ‘Energy recommendations  
2) Press ‘Apply all’ and wait for it to apply each setting  
3) Go to ‘Screen, sleep, & hibernate timeouts’  
4) Set the settings for while the laptop is plugged in to 45 minutes each  
5) Set the settings for while the laptop is on battery (unplugged) to 20 minutes each  
6) Set \_\_\_\_ to 2 hours each (this setting will not be available on all of the laptops)  
7) Turn the ‘Battery percentage’ to on
